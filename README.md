# sb-demo

Demo and prompt for the initial setup of an AI-ready "second brain" in Obsidian.

## Contents

- [`second-brain-inst.md`](second-brain-inst.md) — instructions for Claude Code (or Codex CLI) to set up an Obsidian Vault with a PARA-lite + MOC structure, `CLAUDE.md` / `AGENTS.md`, frontmatter standards, and a git workflow.

## Usage

1. Open your Obsidian Vault folder in Claude Code.
2. Give Claude Code the content of `second-brain-inst.md` as the prompt.
3. Answer its questions (vault path, life/work areas, language).
4. Review the result and commit.
